# Aislely — Privacy Policy

The published privacy policy for the **Aislely** grocery-list app, hosted with GitHub Pages.

**Live URL:** https://oguevar8-commits.github.io/aislely-privacy/

This URL is submitted to Google Play (and later the App Store), so it must stay
reachable and must keep matching what the app actually does.

## Editing

`index.html` is the whole site — a single self-contained page, no build step.
Commit a change to `main` and GitHub Pages republishes it within a minute or two.

When updating, also revise the **Effective** date near the top.

## Keep it accurate

The policy must agree with the app's declared permissions and behaviour:

- Camera — barcode/loyalty-card scanning and item photos (on-device)
- Microphone — voice dictation (transcribed by the device's own speech service)
- Network — only the optional "import recipe from a link" helper

When the **Pro in-app purchase** ships, uncomment the `Purchases` section already
present in `index.html`.
